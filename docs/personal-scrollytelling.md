# Personal Assembly / Unfolded

## 요청과 범위

사용자가 05 Personal Assembly를 선택하고, 큰 화면에서 프로젝트 내용을 자세히 담을 수 있도록 스크롤텔링으로 재설계를 요청했습니다. 이 문서는 해당 요청에 대한 디자인 판단을 기록하며, 실제 콘텐츠 확정본이 아닌 작동하는 재설계 시안을 위한 명세입니다.

## 디자인 판단

카드 목록은 빠른 개요에, 전체 화면 슬라이드는 시각적 인상에 강합니다. 이번에는 긴 내용과 시각 자료를 함께 읽을 수 있도록 **넓은 프로젝트 표지와 고정 비주얼을 가진 세로 서사**를 채택합니다. 스크롤 가로채기, 고정된 읽기 시간, 강제 페이지 넘김은 사용하지 않습니다.

이전 5개 방향 비교 도구는 `directions.html`에 보존하고 새 시안을 기본 진입 화면으로 제공합니다.

## 시각 시스템

- Lavender `#e8e3f3`: 개인 정체성과 Hero의 바탕.
- Indigo `#5145cc`: 이름, 핵심 동작, 첫 프로젝트.
- Lemon `#eced9d`: 두 번째 프로젝트와 실험 영역.
- Plum `#322b45`: 본문과 대비.
- Pearl `#fbfafc`: 긴 글을 읽는 영역.
- Palatino / Palatino Linotype / Georgia: 이름, 프로젝트 제목, 큰 장 제목.
- Avenir Next / Arial / Apple SD Gothic Neo: 탐색과 15–18px 본문.
- 프로젝트는 최대 1720px의 넓은 편집 면을 사용하며, 긴 본문 자체는 약 38–65ch로 제한합니다.

## 인터랙션

1. Hero의 작업물에서 프로젝트로 바로 이동합니다. 스크롤에 따라 작업물 묶음이 천천히 펼쳐집니다.
2. 각 프로젝트는 4개의 장을 사용합니다. 장 수와 본문 길이는 데이터로 바꿀 수 있습니다.
3. 데스크톱에서는 큰 미디어가 고정되며 현재 장에 대응하는 시각 자료가 바뀝니다. 현재 장과 진행 위치를 목차에 표시합니다.
4. 큰 비주얼은 모달에서 더 크게 열 수 있습니다. Escape로 닫고 원래 버튼에 포커스를 돌려줍니다.
5. 프로젝트 개별 보기 URL은 선택한 프로젝트만 긴 케이스 스터디로 보여줍니다.
6. 모바일과 높이가 작은 화면에서는 고정을 해제하고, 각 장의 비주얼과 글을 순서대로 모두 표시합니다. 동작 줄이기에서는 위치 변환과 크로스페이드 없이 읽습니다.

## 콘텐츠 모델

실제 자기소개, 이력, 성과 수치를 작성하지 않습니다. 프로젝트별 `chapters` 배열에 장 제목, 본문 배열, 근거 목록, 미디어 종류·경로·대체 텍스트·설명, 강조 문장을 담습니다. 이미지나 영상이 없으면 자체 제작 그래픽을 표시합니다. 미디어는 `graphic`, `image`, `video`를 지원하며 영상에는 기본 컨트롤을 제공합니다.

긴 설명은 제목, 본문, 참고 목록으로 자연스럽게 늘어납니다. 장의 높이는 고정하지 않고 최소 높이만 사용합니다. 비주얼은 `contain`을 기본으로 하여 실제 화면이나 다이어그램을 자르지 않습니다. 독립 케이스 스터디 URL과 이미지 확대를 제공합니다.

## 자기 검토

스크롤텔링을 단순한 전환 효과로 만들지 않기 위해, 프로젝트의 읽기 구조가 모션보다 먼저 존재하도록 설계합니다. 같은 크기의 작은 카드 반복을 없애고, 프로젝트마다 하나의 큰 표지와 전용 색면을 둡니다. 과도한 장식은 Hero의 별과 겹친 표지에 집중하고 긴 본문 영역은 조용하게 유지합니다.

## 확인할 항목

- 1440px / 1920px 데스크톱의 시각 자료 크기, 긴 본문, 고정 위치.
- 390px / 320px 모바일의 전체 콘텐츠 접근 및 가로 넘침.
- 목차 이동과 스크롤의 현재 장 일치.
- 프로젝트별 개별 URL, 잘못된 프로젝트 요청 처리.
- 이미지 확대, Escape, 모달 포커스 복귀.
- 문법 검사, HTTP 응답, 브라우저 오류.
