렌더링된 공개 페이지에서 이미지 경로를 확인한 뒤 브라우저 자산 도구로 가져왔습니다. 긴 변 1800px, JPEG 품질 88로 변환해 `assets/memento/`에 저장했으며, 세 파일 합계는 약 473KiB입니다. 실제 서비스 화면을 사용하고, 과거 개선 전후 비교 화면으로 가장하지 않았습니다. 서비스 연결 구조도는 실적설명서를 바탕으로 새로 그린 설명 자료입니다.

스토어 링크는 공개 랜딩에서 확인했습니다. 소개 영상 링크는 실적설명서의 보조영상 주소를 사용했습니다. 영상 내용 자체를 새 근거로 사용하지 않았습니다.

## 오늘의 운동회 증명사진

근거: `디미고 자기소개서 초안-3.txt`의 교과 외 활동 중 **지역 대안교육기관 연합 체육대회 부스 운영**.

- 다른 학교 학생들이 연결감을 느끼고 서로 말을 걸 계기를 만들려는 기획 의도.
- 9개 유형 질문에 응답하고 사진을 촬영해 자신의 유형이 담긴 증명사진을 받는 흐름.
- 잘 맞는 유형의 다른 학교 친구 표시.
- 부스 메인 노트북의 학교별·전체 유형 통계.

문서에 없는 참여자 수, 유형 이름, 구현 기술, 운영 날짜, 공개 URL은 만들지 않았습니다. 작은 썸네일은 실제 서비스 캡처가 아닌 자체 제작 설명용 그래픽이며, 실제 인물 사진을 사용하지 않았습니다.
