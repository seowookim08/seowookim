# Phase 1 검증 기록

2026-11-14

## 실행과 제공

- `npm run check`: JavaScript 4개 파일의 문법 검사 성공.
- 비교 페이지, 5개 독립 시안, 콘텐츠 파일, 디자인 제안서의 HTTP 응답: 모두 200.
- 런타임 의존성 및 설치 과정 없음. 로컬 정적 서버로 제공.

## 브라우저 검증

- 독립 시안 5개: 1100px, 390px, 320px에서 문서 너비와 화면 너비가 일치하며 가로 넘침 없음.
- 비교 도구: 데스크톱 1440px 및 모바일 320px에서 확인. 5개 방향 선택과 390px 미리보기 전환 확인.
- Swiss: 프로젝트 색인을 Enter로 펼침, 케이스 스터디 구조 모달 표시, Escape로 닫힘, 호출 버튼으로 포커스 복귀 확인.
- Brutalism: ‘다시 조립’ 버튼으로 구성 상태 변경 확인.
- Premium: 다음 프로젝트로 Project A에서 Project B로 전환, 해당 프로젝트의 모달 표시 확인.
- Digital Art: 정지/재생 상태 전환, 키보드로 밀도를 100%까지 조절, 첫 렌더에서 입자 표시 확인.
- Personal: ‘다음 작업물’로 Project C에서 Project A로 전환, 선택한 작업물로 해당 모달 표시 확인.
- 검사한 브라우저 콘솔의 error/warn 로그 없음.
- 5개 방향의 데스크톱·모바일 스크린샷을 검토하고 `previews/`에 저장.

## 검토 후 수정

- 읽는 본문의 크기를 키워 작은 메타 정보와 구분.
- Canvas 초기 렌더를 애니메이션 프레임에 맡기지 않고 즉시 그리도록 수정.
- 입자장 중심의 여백과 텍스트 뒤 대비를 조정.
- 이름을 데이터에서 파생하도록 구성해 Hero의 하드코딩 제거.

## 범위

디자인 선택을 위한 프로토타입 검증입니다. 실제 인적 정보·프로젝트 미디어·성과 데이터와 전체 사이트 6개 영역은 아직 적용하지 않았습니다. reduced-motion 및 비활성 Canvas 정지는 코드에서 확인했으며, 운영체제 설정 변경을 통한 실기기 검사는 수행하지 않았습니다.
