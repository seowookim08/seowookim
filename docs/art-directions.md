# Personal Portfolio — Five art directions

2026-11-14 · Phase 1 · 디자인 선택 전 비교 프로토타입

## 저장소 분석

작업 시작 시 폴더가 비어 있었으며 Git 저장소, 패키지, 프레임워크, 기존 콘텐츠가 없었습니다. 이번 단계에서는 Node.js 기본 모듈로 제공하는 정적 HTML/CSS/JavaScript 프로토타입을 사용합니다. 프레임워크나 런타임 의존성을 추가하지 않았습니다. 최종 스택은 디자인 선택 후 확정합니다.

## 목적과 범위

테크 기업 채용 담당자와 실무자가 한 사람의 작업과 문제 해결 방식을 이해할 수 있는 포트폴리오의 시각적 방향을 선택합니다. 이 문서는 완성된 사이트의 승인안이 아니라, 선택을 위한 제안서입니다. 사용자가 명시적으로 요청한 비교용 프로토타입만 구현합니다.

5개 시안은 Hero, Selected Works, Thinking & Process를 최소한으로 보여줍니다. Experiments, About, Contact는 아래 각 방향의 전체 구조에 포함되며, 최종 선택 후 구현합니다. 실제 자기소개, 경력, 성과 수치, 연락처, 프로젝트 서술은 창작하지 않습니다. 이름과 프로젝트는 명백한 임시 데이터이며 추상 그래픽만 사용합니다.

## 비교 방법과 설계 원칙

같은 Project A/B/C를 사용하되, ① 읽는 순서, ② 화면의 중심 장치, ③ 프로젝트 탐색 방법, ④ 움직임의 역할을 서로 다르게 설계합니다. 색상 교체만으로 같은 시안이 되지 않게 합니다. 이름과 프로젝트에 관한 실제 사실은 표현하지 않습니다. Hero의 문구는 디자인을 판단하기 위한 임시 문구입니다.

공통 접근성: 기본 스크롤, 시맨틱 HTML, 버튼과 키보드 조작, 포커스 표시, 건너뛰기 링크, reduced-motion 대응. 움직이는 그래픽 옆의 텍스트는 고정합니다. 모든 작품에 모달로 케이스 스터디 정보 구조를 확인할 수 있으며, 실제 내용은 추가하지 않습니다.

## 시각적 자기 검토와 수정

- Swiss: 장식적인 신문 레이아웃을 피하고, 작품 색인 자체를 펼쳐 탐색하게 합니다. 붉은 원 하나가 유일한 큰 제스처입니다.
- Brutalism: 가짜 코드 터미널과 커스텀 커서를 버리고, 구성 자체를 바꾸는 ‘다시 조립’ 동작을 사용합니다. 순서와 읽기 영역은 유지합니다.
- Premium: 어두운 배경의 반복 카드와 장식용 그라데이션을 피하고, 광학 렌즈라는 물성과 단일 작품 스테이지로 바꿉니다. 렌즈의 음영은 물성을 표현하기 위한 용도입니다.
- Digital Art: 범용 우주 입자를 피하고, 유기적인 등고선 형태를 사용합니다. 밀도 조절과 정지를 제공하며 작품 텍스트는 움직이지 않습니다.
- Personal: 따뜻한 크림색·세리프·테라코타 조합을 피하고, 라벤더·인디고·레몬의 작업물 보관함으로 구성합니다. 개인성은 그림 캐릭터 대신 편집과 활자의 호흡에서 나옵니다.

## 구현 대안과 선택

1. 정적 이미지 다섯 장: 구도는 비교하기 쉽지만 직접 조작, 반응형, 스크롤 차이를 판단하기 어렵습니다.
2. 한 개 템플릿의 테마 다섯 개: 빠르지만 요구한 디자인 철학의 차이를 검증하기 어렵습니다.
3. 하나의 비교 도구 + 서로 독립된 다섯 개 DOM 구성: 공통 임시 데이터를 유지하면서 각 방향의 정보 구조와 상호작용을 비교할 수 있어 이번 프로토타입에 채택했습니다. 이는 구현자가 정한 방식이며 최종 사이트 스택에 대한 사용자 선택은 아닙니다.

## 01. Swiss Editorial — The Index

**질서를 통해 드러나는 개성**

포트폴리오를 한 권의 작업집으로. 그리드는 판단력을, 여백은 자신감을 보여줍니다.

### 1. 디자인 철학과 핵심 아이디어

정렬 자체를 시각적 언어로 사용합니다. 이름, 역할, 작품 색인이 하나의 비대칭 그리드에 놓이고, 채용 담당자는 목차를 훑듯 원하는 프로젝트에 바로 진입합니다.

### 2. 컬러와 타이포그래피

- Paper: #f0f0ec
- Ink: #191919
- Signal: #e74330
- Grid: #d3d3cc
- White: #ffffff

Helvetica Neue / Arial. 헤드라인은 500 두께의 촘촘한 대형 산세리프, 본문은 같은 서체의 차분한 기본 폭. 한글은 Apple SD Gothic Neo / Malgun Gothic.

외부 폰트 요청 없이 시스템 서체를 사용하며 플랫폼에 따라 대체됩니다. 최종 방향에서는 서체 라이선스를 확인하고 한글·영문 조합을 확정합니다.

### 3. Hero

좌측의 작은 인적 정보, 화면을 가르는 “Your name.”, 우측의 커다란 붉은 원. 하단의 프로젝트 색인이 곧 다음 섹션의 시작이 됩니다.

### 4. 프로젝트 표현

균일한 카드 대신 출판물의 접지면처럼 가로로 긴 색인을 사용합니다. 선택하면 그래픽, 설명, 케이스 스터디 구조가 아래로 펼쳐집니다.

### 5. 스크롤과 마우스 인터랙션

프로젝트 색인을 클릭하거나 Enter로 펼칩니다. 포인터에 붉은 원이 미세하게 기울고, 스크롤은 브라우저의 기본 동작을 유지합니다.

### 6. 전체 페이지 레이아웃

비대칭 표지 → 펼침형 작품 색인 → 넓은 사고 과정 스프레드 → 작은 실험 색인 → 여백 중심 About → 연락처 후면. 모두 공통 수직 축에 정렬합니다.

1. Hero / 비대칭 표지
2. Selected Works / 펼침형 색인
3. Thinking & Process / 편집 스프레드
4. Experiments / 작은 색인
5. About / 인물과 관점
6. Contact / 작업집의 뒷면

```text
┌ 작은 소개 ────────── 탐색 ┐
│ Your name.       ●      │
│                   소개  │
├ Project A ────────── ＋ ┤
├     그래픽     / 설명    ┤
├ Project B ────────── ＋ ┤
└ 사고 과정 / 실험 / 연락처 ┘
```

데스크톱에서는 위 구도를 따르며, 모바일에서는 읽는 순서대로 1열로 재배치합니다. 헤드라인은 왼쪽 정렬을 기본으로 하며 Premium과 Digital Art의 Hero만 중앙 정렬합니다. 작품 요약과 본문은 모든 방향에서 왼쪽 정렬합니다.

### 7. 차별점과 판단할 점

장식적인 편집 스타일 대신, 실제로 탐색할 수 있는 목차가 사이트의 주인공입니다. 작품이 늘어도 한눈에 읽히는 구조를 유지합니다.

정보 전달과 단정한 인상이 강점입니다. 모션이나 그래픽 자체의 존재감은 다른 방향보다 절제됩니다.

## 02. Digital Brutalism — Hard Cut

**완성된 화면보다 만드는 태도**

자르고, 겹치고, 다시 맞추기. 작업판처럼 직접적인 인터페이스에 창작자의 태도를 담습니다.

### 1. 디자인 철학과 핵심 아이디어

브라우저를 완성된 전시장이 아닌 조립 중인 작업판으로 바라봅니다. 거친 비례와 단호한 경계를 쓰되 모든 조작은 명확한 버튼과 키보드로 접근할 수 있게 합니다.

### 2. 컬러와 타이포그래피

- White: #ffffff
- Black: #000000
- Cobalt: #2750df
- Tape: #e4ec3d
- Concrete: #d9d9d9

Impact / Haettenschweiler를 헤드라인에, Arial Black을 보조 제목에 사용합니다. 본문은 Arial / Apple SD Gothic Neo. 장식적인 코드 폰트는 생략합니다.

외부 폰트 요청 없이 시스템 서체를 사용하며 플랫폼에 따라 대체됩니다. 최종 방향에서는 서체 라이선스를 확인하고 한글·영문 조합을 확정합니다.

### 3. Hero

거대한 “YOUR NAME”을 굵은 프레임에 밀어 넣고, 코발트색 빔과 노란 작업 메모를 교차 배치합니다. “다시 조립” 버튼으로 실제 구성이 바뀝니다.

### 4. 프로젝트 표현

가로로 연속된 작업판이 화면을 점유합니다. 각 작품은 하나의 색면과 크기가 다른 활자로 구성하고, 버튼을 누르면 케이스 스터디 개요를 엽니다.

### 5. 스크롤과 마우스 인터랙션

“다시 조립”은 오브젝트의 회전과 배치를 바꿉니다. 키보드로도 같은 결과를 얻으며, 작품에 포커스하면 표면의 색 대비가 바뀝니다.

### 6. 전체 페이지 레이아웃

포스터형 Hero → 세로로 쌓인 작업판 → 의사결정 기록 → 실험 벽 → 간결한 프로필 → 큰 연락 버튼. 거친 화면 안에 읽기 순서는 고정합니다.

1. Hero / 타이포그래픽 포스터
2. Selected Works / 작업판
3. Thinking & Process / 결정 기록
4. Experiments / 실험 벽
5. About / 작업자 메모
6. Contact / 큰 연락 버튼

```text
┏ YOUR ━━━━━━━━━━━━━━━━┓
┃ NAME       ╱ 빔 ╱    ┃
┃    [메모]   [다시 조립]┃
┣ A ━━━━━━━ 그래픽 ━━━━┫
┣ B ━━━━━━━ 그래픽 ━━━━┫
┗ 기록 / 실험 / 연락 ━━━━┛
```

데스크톱에서는 위 구도를 따르며, 모바일에서는 읽는 순서대로 1열로 재배치합니다. 헤드라인은 왼쪽 정렬을 기본으로 하며 Premium과 Digital Art의 Hero만 중앙 정렬합니다. 작품 요약과 본문은 모든 방향에서 왼쪽 정렬합니다.

### 7. 차별점과 판단할 점

커서 장난이나 가짜 터미널에 의존하지 않습니다. 조립을 바꾸는 작은 행동 하나가 만드는 사람의 정체성을 표현합니다.

기억에 남는 인상이 강점입니다. 보수적인 채용 환경에는 시각적인 소음으로 느껴질 수 있습니다.

## 03. Premium Technology — Optical System

**빛처럼 정밀하게 설계된 경험**

렌즈가 초점을 맞추듯, 복잡한 작업에서 핵심을 선명하게 드러내는 제품 중심의 포트폴리오.

### 1. 디자인 철학과 핵심 아이디어

광학 기기의 정밀함을 인터페이스로 번역합니다. 차가운 무채색, 반투명 레이어, 넓은 광학적 여백으로 제품을 만드는 사람의 섬세함을 전달합니다.

### 2. 컬러와 타이포그래피

- Graphite: #121619
- Silver: #e5e9ec
- Ice: #99c7f7
- Steel: #91a1aa
- Depth: #242c33

Avenir Next / Avenir / Segoe UI. 헤드라인은 중간 두께와 좁은 자간, 본문은 넉넉한 행간. 한글은 Apple SD Gothic Neo / Malgun Gothic.

외부 폰트 요청 없이 시스템 서체를 사용하며 플랫폼에 따라 대체됩니다. 최종 방향에서는 서체 라이선스를 확인하고 한글·영문 조합을 확정합니다.

### 3. Hero

중앙 정렬된 이름과 소개 아래, 다중 링으로 구성한 커다란 광학 렌즈가 놓입니다. 타이포그래피와 그래픽이 겹치지 않게 시각적 무게를 분배합니다.

### 4. 프로젝트 표현

하나의 큰 프로젝트 스테이지에 그래픽과 요약을 함께 배치합니다. 이전·다음 버튼이 스테이지를 교체하며 위치 표시로 전체 작품 수를 보여줍니다.

### 5. 스크롤과 마우스 인터랙션

마우스 위치에 렌즈의 하이라이트가 반응합니다. 프로젝트 전환은 짧은 디졸브로 처리하고, 터치와 키보드에서는 버튼으로 동일한 내용을 제공합니다.

### 6. 전체 페이지 레이아웃

중앙 Hero → 단일 프로젝트 스테이지 → 의사결정의 단면 → 가벼운 실험 선반 → 정돈된 About → 간결한 연락 영역. 화면마다 하나의 초점을 둡니다.

1. Hero / 광학적 중심
2. Selected Works / 단일 스테이지
3. Thinking & Process / 의사결정의 단면
4. Experiments / 실험 선반
5. About / 정돈된 프로필
6. Contact / 한 가지 행동

```text
┌───────────────────────┐
│        Your name.     │
│          소개          │
│         ◉ 렌즈         │
├   [ 그래픽 / 설명 ]    ┤
│         ‹ A ›         │
└ 과정 / 실험 / 프로필 ──┘
```

데스크톱에서는 위 구도를 따르며, 모바일에서는 읽는 순서대로 1열로 재배치합니다. 헤드라인은 왼쪽 정렬을 기본으로 하며 Premium과 Digital Art의 Hero만 중앙 정렬합니다. 작품 요약과 본문은 모든 방향에서 왼쪽 정렬합니다.

### 7. 차별점과 판단할 점

어두운 배경 위에 SaaS 카드를 나열하는 대신, 렌즈라는 일관된 물성과 단일 스테이지를 사용합니다. 작품마다 제품 발표 같은 집중도를 줍니다.

정제된 제품 감각이 강점입니다. 개인의 개성은 프로젝트의 내용과 의사결정 설명에서 더 구체적으로 보완해야 합니다.

## 04. Interactive Digital Art — Field Notes

**움직임으로 시작하는 대화**

커서가 지나간 자리에 새로운 형태가 생깁니다. 작품을 읽기 전에 만드는 방식을 경험합니다.

### 1. 디자인 철학과 핵심 아이디어

이름을 둘러싼 입자장을 작은 디지털 작품으로 사용합니다. 첫 화면은 감각으로 기억하고, 이후 작품과 과정은 명료한 텍스트 중심 구조로 읽게 합니다.

### 2. 컬러와 타이포그래피

- Forest: #12372c
- Mist: #edf3dc
- Pollen: #d2ff6a
- Moss: #547c5c
- Shade: #1e4a3d

Georgia / Times New Roman의 부드러운 세리프와 Arial / Apple SD Gothic Neo의 실용적인 본문. 코드 실험을 예상 밖의 유기적 활자와 결합합니다.

외부 폰트 요청 없이 시스템 서체를 사용하며 플랫폼에 따라 대체됩니다. 최종 방향에서는 서체 라이선스를 확인하고 한글·영문 조합을 확정합니다.

### 3. Hero

숲빛 화면 안에 입자로 그린 유기적인 장이 놓입니다. “Your name.”은 그래픽 중앙의 조용한 빈 공간에 자리하고, 아래에서 밀도를 직접 조절합니다.

### 4. 프로젝트 표현

작품은 연속된 가로 행으로 보여줍니다. 그래픽 썸네일은 작품 목록의 일부이고 텍스트와 버튼은 항상 고정되어 움직이는 표면과 읽는 영역을 구분합니다.

### 5. 스크롤과 마우스 인터랙션

포인터 주변의 입자가 밀려났다가 돌아옵니다. 밀도 슬라이더로 결과를 바꾸고 정지 버튼으로 멈출 수 있습니다. 동작 줄이기 설정에서는 정지 화면으로 시작합니다.

### 6. 전체 페이지 레이아웃

반응형 입자 Hero → 명료한 작품 목록 → 시각화된 사고 과정 → 실행 가능한 실험 목록 → 정적인 About → Contact. 동적 화면과 정적 읽기를 번갈아 배치합니다.

1. Hero / 반응하는 입자장
2. Selected Works / 정적인 작품 목록
3. Thinking & Process / 과정의 시각화
4. Experiments / 실행 가능한 실험
5. About / 정적인 읽기
6. Contact / 연락처

```text
┌ · · · · · · · · · · · ┐
│ · ·   Your name.  · · │
│ · · · 입자장 · · · · · │
│ 밀도 ───●─── [정지]    │
├ Project A    [썸네일] ┤
├ Project B    [썸네일] ┤
└ 과정 / 실험 / 연락처 ──┘
```

데스크톱에서는 위 구도를 따르며, 모바일에서는 읽는 순서대로 1열로 재배치합니다. 헤드라인은 왼쪽 정렬을 기본으로 하며 Premium과 Digital Art의 Hero만 중앙 정렬합니다. 작품 요약과 본문은 모든 방향에서 왼쪽 정렬합니다.

### 7. 차별점과 판단할 점

범용적인 우주 입자나 소용돌이 대신 종이 위 등고선 같은 유기적 장을 사용합니다. 장식을 넘어 조절할 수 있는 실제 실험을 보여줍니다.

기술과 시각 감각을 함께 보여주는 데 강점이 있습니다. 시각적 효과가 실제 프로젝트의 근거를 대신하지 않도록 본문을 명료하게 유지해야 합니다.

## 05. Contemporary Identity — Personal Assembly

**하나의 사람, 여러 개의 시선**

접어둔 작업물, 손으로 남긴 표시, 자유로운 활자. 정해진 틀보다 한 사람의 편집 감각을 보여줍니다.

### 1. 디자인 철학과 핵심 아이디어

포트폴리오를 사적인 작업물 보관함으로 바라봅니다. 세리프의 인물성과 선명한 라벤더 색면을 결합하고, 겹쳐 놓은 작품을 고르는 경험으로 개인의 시선을 드러냅니다.

### 2. 컬러와 타이포그래피

- Lavender: #e8e3f3
- Indigo: #5145cc
- Lemon: #eced9d
- Plum: #322b45
- Pearl: #fbfafc

Palatino / Palatino Linotype / Book Antiqua를 이름과 제목에 사용합니다. Avenir Next / Arial을 탐색과 본문에 사용해 개인적인 활자와 실용적인 정보를 구분합니다.

외부 폰트 요청 없이 시스템 서체를 사용하며 플랫폼에 따라 대체됩니다. 최종 방향에서는 서체 라이선스를 확인하고 한글·영문 조합을 확정합니다.

### 3. Hero

왼쪽의 세리프 이름과 짧은 소개, 오른쪽의 겹쳐진 작업물 세 장. 별 모양의 작은 제작 그래픽이 두 영역을 연결하며 인물과 작품을 동시에 보여줍니다.

### 4. 프로젝트 표현

Hero의 겹친 작업물을 버튼으로 한 장씩 앞으로 꺼낼 수 있습니다. 아래의 서로 다른 비례의 작품 구성은 각각 독립적인 아트 디렉션을 허용합니다.

### 5. 스크롤과 마우스 인터랙션

겹친 작업물은 클릭 또는 “다음 작업물” 버튼으로 순서를 바꿉니다. 작품의 움직임은 짧고 직접적이며, 스크롤에서는 비대칭 정렬을 점진적으로 드러냅니다.

### 6. 전체 페이지 레이아웃

인물과 작업물 Hero → 크기가 다른 작품 페어 → 짧은 관점 에세이 → 작은 수집품 같은 실험 → 개인적인 About → 편지 같은 Contact. 각 섹션은 서로 다른 호흡을 가집니다.

1. Hero / 인물과 겹친 작업물
2. Selected Works / 비대칭 작품 페어
3. Thinking & Process / 관점 에세이
4. Experiments / 작은 수집품
5. About / 개인적인 소개
6. Contact / 편지의 끝
