# Project C — Wonderwall

## 사용자가 제공한 사실

- 해외 록 매거진 Instagram 계정 `@wonderwall_withrock`을 직접 운영.
- 운영 당시 최고 팔로워 수 3,000명 이상.
- 릴스 영상을 직접 편집했고 높은 조회수를 기록.
- 최고 릴스 조회수 질문에 대한 추가 답변: **193만 회**.
- 티셔츠를 직접 만들어 판매.

성과는 **운영 당시의 최고 기록**으로 표현했습니다. 단일 릴스 최고 조회수와 계정 전체의 최고 팔로워 수를 구분했습니다. 193만 회를 기록한 특정 릴스 URL은 제공되지 않았으므로, 공개 예시 릴스에 그 수치를 붙이지 않았습니다.

제작한 티셔츠의 디자인·인쇄 방식·판매 수량·가격·매출·제작 기간·편집 도구는 추정하지 않았습니다. 티셔츠 장의 그림은 직접 제작·판매 활동을 설명하는 벡터 그래픽이며 실제 제품 사진이나 디자인 시안으로 제시하지 않았습니다.

## 공개 계정 확인

출처: [원더월 Instagram](https://www.instagram.com/wonderwall_withrock/). 2026-11-14 공개 브라우저 화면에서 계정명 원더월, 소개 ‘록을 다룹니다’, 매거진 게시물과 릴스 링크를 확인했습니다.

확인 당시 공개 팔로워 수 2,605명은 사용자가 말한 과거 최고 기록과 다른 값입니다. 포트폴리오에는 요청한 역사적 최고 기록을 사용했습니다. 릴스 탭은 로그인 안내가 표시되어 공개 화면에서 조회수 최고 기록을 독립적으로 확인하지는 못했습니다.

공개 자료로 연결한 예시:

- 매거진 게시물: `https://www.instagram.com/wonderwall_withrock/p/DG-QwFOyxCv/`
- 릴스 예시: `https://www.instagram.com/wonderwall_withrock/reel/DGvRSswxFLn/`
- 릴스 예시: `https://www.instagram.com/wonderwall_withrock/reel/DHxTnv1y0SA/`

관찰된 공개 이미지 세 개를 브라우저 자산 도구로 가져와 JPEG 원본 그대로 `assets/wonderwall/`에 저장했습니다. 이미지들을 해당 게시물로 연결했으며 로그인 안내를 우회하거나 계정에 로그인하지 않았습니다. 비공개 인사이트, 판매 정보, 메시지는 열지 않았습니다.

## 적용

- `rock-content.js`: 실제 프로젝트 설명, 역할, 최고 기록, 네 개 장.
- `rock-media.js`: 공개 게시물 갤러리, 릴스 커버, 성과 시각화, 티셔츠 활동 그래픽.
- `rock.css`: Project C의 편집 구도와 반응형 미디어.
- `story-content.js`: 기존 임시 Project C 교체.
- `story.js`: 현재 공개 수치와 운영 당시 최고 기록을 구분해 렌더링하는 공통 성과 영역.

기존 Project A 메멘토, Project B Problem, 운동회 미니 프로젝트와 Seowoo Kim 이름은 유지했습니다.
